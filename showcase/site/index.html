From equations
to evidence.

These six studies began in the Umetno zaznavanje (Machine Perception) course. They explore how images become arrays, features, correspondences and geometric models.

The portfolio preserves the original submissions and adds reusable modules, numerical checks and a visual way to inspect the results.

Read the implementation notes ↗
  1. 01

    Implement the idea

    Histograms, convolution, Hough voting, DLT, triangulation and dual PCA expressed as Python and NumPy operations.

  2. 02

    Check the mathematics

    Known transforms, synthetic correspondences and reconstruction invariants make the results testable.

  3. 03

    Make it reproducible

    One command regenerates the figures and metrics. The browser explores these saved Python outputs.
